# SlopLens

在**你自己的浏览器**里给 X 时间线打一个「空话指数」。

分高的加角标，拿不准的只留记号，低信息的灰标，内容不完整的打个淡记号。
**它绝不替你下判决。**

纯本地规则引擎，零服务器、零账号、零遥测。深检是可选的 BYOK。

> English: [README.en.md](README.en.md)。完整规格（阈值、判据、已知的坑）在
> [`sloplens/README.md`](sloplens/README.md)。

---

## 它不是什么

- **它不是「AI 检测器」**。它不说「这是 AI 写的」，它说「这条内容的可判定信号有多强」，
  而且永远把理由一起给你。
- **不上传任何东西**。没有服务器，没有 key，没有遥测。所有打分在页面里完成。

## 为什么这样设计

单条推文只有 280 字符，信息量不足以支撑「是 / 不是」的判决。
任何声称能判准的工具，误伤率都会高到你不敢用。

所以这里退一步：**分档 + 给理由 + 可调阈值**。
你永远知道它为什么这么标，也永远可以不同意它。

## 安装（开发者模式）

目前没有上架任何商店，用「加载已解压」的方式装：

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选 **`sloplens/`** 这个文件夹
4. 打开 x.com，正常刷

## 分档

分数叫**空话指数**，0–100，**越高越空**——它是「这条内容有多套路化」的分数，不是质量分。

| 档位 | 判定依据 | 界面 |
|---|---|---|
| **空话较多** | 空话指数 ≥ 70 | 红色角标；「折叠」模式下折叠，点一下展开 |
| **存疑** | 45 – 69 | 黄色角标，**绝不折叠** |
| **低信息** | 具体信息 ≤ 阈值 | 灰蓝虚线角标，**绝不折叠** |
| **正常** | 都不命中 | 什么都不显示 |
| **需展开**（记号） | 被 X 截断了 | 极淡记号，不显示分数 |
| **半截**（记号） | 作者只发了前半段 | 极淡记号，不显示分数 |

折叠要**两个条件同时成立**：空话 ≥ 70 **且** 具体信息 ≤ 35。
AI 写的但有料 → 只标记；真人写的空话 → 也不折。

## 反馈协议

角标点开有三颗按钮，你**不用判断「像不像 AI」**：

| 你的感受 | 点什么 | 价值 |
|---|---|---|
| 一眼假，能说出依据 | `这是 AI` | 正样本 |
| 有具体细节、亲历、口语 | `这是真人` | 负样本 |
| **觉得怪，但说不出哪怪** | `说不清` | ⭐ 最值钱 |
| 没什么感觉 | 什么都不用点 | 不产生数据，也不产生噪声 |

## 深检（可选）

默认关闭。在设置里填任意 **OpenAI 兼容**接口（默认 DeepSeek，也支持 OpenAI /
本机 Ollama / 自建网关），点推文面板上的「深检」才会发请求。

- 只在点击时调用，刷 500 条花费为 0
- 有每日上限（默认 200 次）
- **可选**带上你标过的样本做 few-shot（默认关）。开了以后发出去的不只一条推文，
  所以必须你自己勾——见隐私说明
- **不改变折叠决策**——模型也会错，折叠是有代价的动作

## 隐私

默认不联网。唯一的外连是你自己触发的深检：把**那一条**推文的文本发给你自己填的地址，
用你自己的 key。key 在本地是明文存的，请用一把专用、限额的 key。

如果你在设置里勾了「带上我标过的样本」，深检会再加最多 4 条 AI + 4 条你标成真人的样本原文
（每条截断到 160 字）。**默认是关的**，因为这条改变了「只发一条」的承诺。

详见 [PRIVACY.md](PRIVACY.md)。

## 开发

```bash
node tools/calibrate.mjs samples.json     # 用你自己的标注反推阈值
node test/run.mjs                         # 引擎回归，0 依赖
node test/llm.test.mjs                    # LLM 客户端，0 依赖，起本地假服务
npm i -D jsdom && node test/dom.test.mjs  # DOM 冒烟
python3 tools/make-icons.py               # 重画图标（需要 Pillow）
```

`engine.js` 和 `llm.js` 刻意不碰 DOM 和 storage，所以能在 Node 里直接跑测试。

## 状态

v0.10.0，只支持 x.com。规则层是纯文本处理，加别的站点只差一个 DOM 适配器——
路线图见 [`sloplens/README.md`](sloplens/README.md)。

## 免责

判定结果是统计信号，不是事实认定。不要拿它去公开指认某个账号，也不要把它当举报依据。
它只服务于一件事：**你自己要不要读这条内容**。
